How it works

The app extracts URL features such as length, dots, subdomains, HTTPS usage, IP addresses and suspicious keywords.

Model

A Random Forest classifier is trained with the bundled educational dataset and saved locally using joblib.

Important

This is an educational project, not a production security scanner or a replacement for browser security tools.
